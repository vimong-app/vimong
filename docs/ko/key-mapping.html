키 매핑

Vimong에서 사용할 수 있는 전체 키 매핑입니다.

탐색

j / k아래 / 위 스크롤
h / l좌 / 우 스크롤
Ctrl+D / Ctrl+U반 페이지 아래/위로 스크롤
J / K다음 / 이전 페이지
gg첫 페이지
ga클릭한 글자의 아스키/유니코드 값 보기
G마지막 페이지
nGn번째 페이지로 이동 (예: 5G)
m{a-z}현재 위치를 마크로 저장
'{a-z} / `{a-z}저장한 마크로 이동
f하이퍼링크 힌트 표시 후 이동
[ / ]사이드바 탭 전환 (썸네일/목차/검색)
Tab사이드바 ↔ 본문 포커스 전환
j / k (사이드바 포커스 시)썸네일/목차/검색결과 항목 이동
← / → 또는 h / l (목차 포커스 시)챕터 접기/펼치기, 부모/자식 이동
Cmd+Shift+T사이드바 보이기/숨기기
r / R페이지 90도 시계/반시계 방향 회전 (PDF, HWP 모두 지원)
p프레젠테이션 모드 (전체화면으로 전환하고 한 페이지를 화면에 꽉 채워 슬라이드처럼 보기)

확대/축소

zi확대
zo축소
z0100% 크기
zh가로 맞춤
zv / zz세로 맞춤
Cmd++확대
Cmd+-축소

파일

:e파일 열기 (다이얼로그)
:e {경로}경로로 파일 열기 (Cmd+V 붙여넣기 가능)
:q / Cmd+W현재 탭 닫기
:?단축키 도움말 열기
:cmd명령어 도움말 열기
:oss오픈소스 라이선스 열기
Cmd+I문서 정보
:attachments / :att첨부파일 목록 보기 (사이드바)
:print / Cmd+P인쇄
:export [-m] [-p] [pagespec] <path> / Cmd+Shift+E이미지(PNG/JPG)나 PDF로 내보내기. pagespec 없으면 선택한 페이지, 없으면 현재 페이지(PDF는 전체). -p로 암호 설정(PDF 전용)
:images현재 페이지에 포함된 이미지를 원본 그대로 폴더에 저장
:view {mode}보기 모드 전환 — single/1, single-continuous/1c, two/2, two-continuous/2c, horizontal-continuous/h
dd (시작 화면)선택한 최근 파일을 목록에서 삭제

검색

/ / Cmd+F검색 (한국어/일본어/중국어 지원)
n / N다음 / 이전 검색 결과
:nohlsearch / :noh검색 하이라이트 끄기 (다음 검색/n/N에서 다시 켜짐)
...\c / ...\C검색어 끝에 붙이면 대소문자 무시/구분 (Aa 토글보다 우선)
...\r / ...\R검색어 끝에 붙이면 정규식 강제/해제 (.* 토글보다 우선)

지원 정규식 문법 (vim magic 모드)

. * ^ $임의의 한 문자 / 0회 이상 반복 / 줄 시작 / 줄 끝
[...] [^...]문자 클래스 / 부정 문자 클래스
\+ \? \=1회 이상 / 0회 또는 1회
\{n,m} \{-...}반복 횟수 지정 (앞에 -를 붙이면 최소 매칭)
\( \) \|그룹 / OR
\< \>단어 경계 (단어 시작 / 끝)
\zs \ze매치 범위(하이라이트) 시작 / 끝 지정
\d \D \w \W \s \S숫자 / 비숫자 / 단어 문자 / 비단어 문자 / 공백 / 비공백
\a \l \u \x \o \h알파벳 / 소문자 / 대문자 / 16진수 / 8진수 / 식별자 문자 (대문자는 부정)

미지원: 룩어라운드(\@= \@! \@<= \@<!), 역참조(\1~\9), \%(...\)

마크다운

.md 문서를 열었을 때만 동작합니다. 자세한 내용은 마크다운 지원 페이지 참고.

gc / gp / gs코드 / 미리보기 / 분할 화면으로 전환
:md code / :md preview / :md split같은 동작을 명령으로 (짧게 :md c/p/s도 가능)
:md theme [이름]미리보기 테마 전환 (이름 없으면 다음 테마로 순환)

탭

Cmd+T새 탭
:tabnew새 탭
:tabnew {경로} / :tabe {경로}새 탭으로 파일 열기
:tabclose현재 탭 닫기
:tabonly / :tabo현재 탭만 남기고 나머지 탭 모두 닫기
gt / gT다음 / 이전 탭
Cmd+Shift+] / Cmd+Shift+[다음 / 이전 탭
ngtn번째 탭으로 이동 (예: 2gt)
:tabmove [N]탭 위치 이동 (인자 없으면 맨 끝, 0은 맨 앞, +N/-N은 상대 이동)
