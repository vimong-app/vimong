HWP 문서 지원

rhwp로 HWP파일도 변환없이 바로 보여줍니다.

지원하는 기능

  • · Vim 키바인딩 이동 — j/k 스크롤, gg/G, nG, 마크(m/')
  • · 확대/축소 — zi/zo/z0/zh/zv/zz
  • · 페이지 회전 — r/R
  • · 정규식 검색

지원하지 않는 기능

HWP는 최소 뷰어로 지원돼서, PDF에서 되는 기능 중 일부는 안 됩니다.

  • · 하이퍼링크 힌트(f) — 링크가 있어도 힌트가 뜨지 않습니다
  • · 페이지 내보내기(:export) / PDF 추출(:w) — 지원하지 않습니다
