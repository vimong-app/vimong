분할 보기

지원 형식:PDFEPUBXPS이미지등 (HWP·마크다운 제외)

본문을 읽으면서 그림이나 참고문헌을 옆에 띄워 두거나, 논문과 부록을 나란히 놓고 봅니다. Vim처럼 :vsplit과 :split으로 화면을 두 창으로 나누고, Ctrl+W로 창 사이를 오갑니다.

:split [path] / :sp위아래로 나누기 — path 파일, 없으면 지금 문서
:vsplit [path] / :vs좌우로 나누기 — path 파일, 없으면 지금 문서
:e [path]분할 창에서: 그 창의 문서만 바꾸기
Ctrl+W w다른 창으로 전환
Ctrl+W h / j / k / l그 방향에 있는 창으로 이동
:q / :close / Ctrl+W c지금 창 닫기 — 다른 창은 남음 (문서는 닫히지 않음)
:only / Ctrl+W o다른 창 닫기

창마다 따로

분할 창은 위치·배율·회전을 따로 가집니다. j/k, J/K, gg/G, {n}G, Ctrl+D/U, zi/zo/zh/zv/zc, r/R가 모두 활성 창에서 동작합니다. 탭을 바꿔도 자기 문서를 유지하고, 파일이 디스크에서 바뀌면 다시 읽으며(LaTeX 작업에 편리), 탭 세션 복원 때 함께 되살아납니다.

사이드바와 검색은 활성 창을 따라갑니다

사이드바 목차는 활성 창의 것입니다 — 제목을 고르면 그 창이 이동하고, 분할 창이 다른 문서면 그 문서의 목차가 보입니다. 검색도 창마다 따로입니다 — /, n/N, 검색 패널이 활성 창 기준으로 동작하고, 한 창에서 검색해도 다른 창의 결과는 그대로 남습니다. 나머지 사이드바 탭은 메인 창 문서 기준입니다.

분할 창은 MuPDF가 여는 형식(PDF, EPUB, XPS, 이미지 등)에서 동작합니다. HWP와 마크다운 파일은 메인 창에서만 열립니다.
