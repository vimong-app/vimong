마크다운 지원

PDF와 똑같이 .md 파일을 vi 키바인딩으로 다룹니다. 코드 원문 그대로 보기, 렌더링된 미리보기, 둘을 나란히 두는 분할 화면을 오갈 수 있습니다.

화면 전환

gc / gp / gs코드 / 미리보기 / 분할 화면으로 전환
:md code / :md preview / :md split같은 동작을 명령으로 (짧게 :md c/p/s도 됨)
:md theme {이름}미리보기 컬러 테마 전환. 이름 없이 쓰면 다음 테마로 순환, Tab으로 이름 자동완성

분할 화면에서는 코드와 미리보기가 같은 위치를 보여주도록 스크롤이 서로 맞춰 움직입니다.
