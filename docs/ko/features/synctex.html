SyncTeX 지원

LaTeX 문서를 쓰다 보면 "PDF의 이 문장이 소스 몇 번째 줄이지?", "지금 편집 중인 이 줄이 PDF 어디쯤 나오지?"를 계속 오가게 됩니다. SyncTeX 연동으로 편집기와 PDF 사이를 양방향으로 바로 이동할 수 있습니다.

역방향 검색 (PDF → 소스)

Shift+Cmd+클릭 / Shift+Ctrl+클릭PDF에서 클릭한 위치에 대응하는 LaTeX 소스 줄로 편집기를 열어 바로 이동

정방향 검색 (소스 → PDF)

편집기 쪽에서 SyncTeX 정방향 검색을 실행하면 Vimong이 해당 PDF 페이지의 정확한 위치로 이동합니다.

편집기 연동

설정의 SyncTeX 탭에서 역방향 검색이 열 편집기 명령을 지정합니다. VS Code 프리셋을 바로 쓰거나, %f(파일) %l(줄) %c(열) 자리표시자를 쓴 사용자 지정 명령을 입력할 수 있습니다.

TeXShop은 SyncTeX용 CLI가 따로 없어서 도우미 스크립트가 필요한데, 설정 화면에서 설치 명령을 복사해 터미널에 붙여넣기만 하면 됩니다.
