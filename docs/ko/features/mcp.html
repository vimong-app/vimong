AI 연동

지원 형식:PDFEPUBXPS이미지등 (HWP 제외, 마크다운은 앱 안에서만)

지금 읽고 있는 문서에 AI를 쓰는 방법은 두 가지입니다:

Vimong 안에서a를 누르고 내 컴퓨터에서 돌아가는 모델(Ollama)에게 묻습니다. 문서가 컴퓨터 밖으로 나가지 않습니다
다른 AI 앱에서Claude 같은 어시스턴트가 내장 MCP 서버를 통해 지금 보는 페이지를 읽고, 그림을 보고, 문장을 하이라이트하고, 페이지를 이동합니다

Vimong 안에서 (로컬 AI)

a를 누르면 사이드바에 AI 탭이 열리고, 지금 읽고 있는 페이지에 대해 물어볼 수 있습니다. 답은 Ollama로 내 컴퓨터에서 돌아가는 모델이 만들기 때문에 문서가 컴퓨터 밖으로 나가지 않고, 계정이나 API 키도 필요 없습니다.

AI가 보는 내용

질문과 함께 보낼 내용은 패널 위쪽 메뉴에서 고릅니다. 선택한 텍스트는 항상 함께 보내므로, "이거 번역해줘", "이게 무슨 뜻이야?"는 선택한 부분에 대해 답합니다.

현재 페이지 텍스트지금 보는 페이지의 텍스트 — "이 페이지 요약해줘"
현재 파일 전체 텍스트지금 보는 파일 전체의 텍스트 — "결론이 뭐야?" (긴 파일은 아래 참고)
현재 페이지 텍스트 + 이미지페이지 텍스트와 페이지를 찍은 그림 — 그림, 표, 수식, 스캔 페이지. 비전 모델이 필요합니다

"현재 파일 전체 텍스트"에서 장, 절, 페이지 범위를 물으면("16장 요약해줘") Vimong이 목차에서 그 부분을 찾아 모든 페이지를 읽습니다. 길면 여러 번에 나눠 읽고, 무엇을 읽었는지 답 위에 표시합니다. 그 밖의 질문은 qwen3, llama3.1처럼 도구를 지원하는 모델이면 파일을 검색해서 답하고, 그 밖의 모델에서는 앞에서부터 4만 자까지만 보냅니다.

범위를 직접 정하려면 목차 항목을 우클릭하고(또는 항목에서 o) AI에게 묻기...를 고르세요. AI 탭 입력창 위에 범위가 표시되고, ✕로 해제할 때까지 모든 질문이 그 부분 전체를 읽고 답합니다.

문서는 질문하는 순간에 읽기 때문에, 페이지를 넘긴 뒤에는 "이 페이지"가 지금 페이지를 가리킵니다. 대화는 파일마다 따로 남습니다.

설정

Ollama를 설치하고 모델을 받습니다:

brew install ollama
ollama serve            # Ollama 앱을 쓰면 필요 없음
ollama pull qwen3:8b    # 텍스트 질문용
ollama pull qwen2.5vl:7b  # 그림·스캔 페이지용 (비전)

모델은 패널의 메뉴에서 고릅니다. 나중에 받은 모델은 Vimong을 다시 실행하면 나타납니다. 메모리 16GB Mac에서는 7~14B(5~9GB) 모델이 무난하고, 비전 모델로는 gemma3:12b, llama3.2-vision:11b도 쓸 수 있습니다.

Vimong은 127.0.0.1:11434의 Ollama에 연결합니다. OLLAMA_HOST가 설정돼 있으면 그 주소를 씁니다.

알아두면 좋은 점

파일 내용을 보낼 수 없을 때(암호로 보호된 PDF, HWP 파일, 텍스트가 없는 스캔 페이지)는 답 위에 그 이유가 표시되고, 답은 질문만으로 만들어집니다. 스캔 페이지는 "현재 페이지 텍스트 + 이미지"로 바꾸세요.

마크다운 파일은 어떤 옵션을 고르든 원문 전체를 보냅니다.

다른 AI 앱에서 (MCP)

Vimong에는 MCP 서버가 내장되어 있어서, Claude 같은 AI 어시스턴트가 Vimong에 열어둔 문서를 직접 다룰 수 있습니다. 텍스트를 채팅창에 복사해 붙일 필요 없이 "이 페이지", "선택한 문장"이라고만 말하면 됩니다.

이런 요청을 할 수 있습니다

"이 페이지 요약해줘"지금 보고 있는 페이지를 읽습니다
"선택한 문장 번역해줘"Vimong에서 선택한 텍스트를 읽습니다
"이 그림 설명해줘"페이지를 이미지로 봅니다 — 그림, 수식, 스캔 페이지
"3장으로 이동해줘"목차에서 3장을 찾아 Vimong 화면을 그 페이지로 옮깁니다
"이 페이지 핵심 주장에 하이라이트하고 각각 코멘트 달아줘"하이라이트를 추가하고, 코멘트는 메모로 붙입니다
"내 하이라이트로 정리 노트 만들어줘"내 하이라이트와 메모를 읽습니다

매번 "Vimong"이라고 말하지 않아도 됩니다. 다른 문서 관련 도구도 함께 연결해 두었다면 "Vimong에서"라고 붙이면 확실합니다.

설정

Claude Code에 등록:

claude mcp add -s user vimong -- /Applications/Vimong.app/Contents/MacOS/vimong --mcp

Claude Desktop은 ~/Library/Application Support/Claude/claude_desktop_config.json에 아래 내용을 추가한 뒤, Claude Desktop을 완전히 종료했다가 다시 실행하세요:

{
  "mcpServers": {
    "vimong": {
      "command": "/Applications/Vimong.app/Contents/MacOS/vimong",
      "args": ["--mcp"]
    }
  }
}

Windows와 Linux에서는 설치된 vimong 실행 파일 경로를 쓰면 됩니다. 다른 MCP 클라이언트도 같은 방식으로, vimong --mcp를 stdio 서버로 실행하도록 등록하면 됩니다.

get_current_view문서 경로, 현재 페이지, 전체 페이지 수

get_notes하이라이트(하이라이트한 문장 포함)와 메모
get_outline목차와 페이지 번호

페이지 인자를 생략하면 지금 보는 페이지가 대상이고, 3, 1-3,7, all 형식도 받습니다.

알아두면 좋은 점

Vimong이 실행 중이고 문서가 열려 있어야 합니다. AI는 요청할 때마다 지금 보고 있는 문서와 페이지를 다시 확인하므로, 대화 도중에 문서나 페이지를 바꿔도 됩니다.

AI가 추가한 하이라이트는 직접 칠한 것과 똑같이 동작합니다. :w로 저장하기 전까지는 파일에 쓰이지 않고, u로 취소할 수 있습니다. 하이라이트와 메모는 PDF 파일에서 동작합니다.

읽기 도구는 디스크의 파일을 읽기 때문에, :w로 저장하지 않은 하이라이트와 메모는 포함되지 않습니다.
