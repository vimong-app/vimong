AI 연동 (MCP)

Vimong에는 MCP 서버가 내장되어 있어서, Claude 같은 AI 어시스턴트가 Vimong에 열어둔 문서를 직접 다룰 수 있습니다. 텍스트를 채팅창에 복사해 붙일 필요 없이 "이 페이지", "선택한 문장"이라고만 말하면 됩니다.

이런 요청을 할 수 있습니다

"이 페이지 요약해줘"지금 보고 있는 페이지를 읽습니다
"선택한 문장 번역해줘"Vimong에서 선택한 텍스트를 읽습니다
"이 그림 설명해줘"페이지를 이미지로 봅니다 — 그림, 수식, 스캔 페이지
"3장으로 이동해줘"목차에서 3장을 찾아 Vimong 화면을 그 페이지로 옮깁니다
"이 페이지 핵심 주장에 하이라이트하고 각각 코멘트 달아줘"하이라이트를 추가하고, 코멘트는 메모로 붙입니다
"내 하이라이트로 정리 노트 만들어줘"내 하이라이트와 메모를 읽습니다

매번 "Vimong"이라고 말하지 않아도 됩니다. 다른 문서 관련 도구도 함께 연결해 두었다면 "Vimong에서"라고 붙이면 확실합니다.

설정

Claude Code에 등록:

claude mcp add -s user vimong -- /Applications/Vimong.app/Contents/MacOS/vimong --mcp

Claude Desktop은 ~/Library/Application Support/Claude/claude_desktop_config.json에 아래 내용을 추가한 뒤, Claude Desktop을 완전히 종료했다가 다시 실행하세요:

{
  "mcpServers": {
    "vimong": {
      "command": "/Applications/Vimong.app/Contents/MacOS/vimong",
      "args": ["--mcp"]
    }
  }
}

Windows와 Linux에서는 설치된 vimong 실행 파일 경로를 쓰면 됩니다. 다른 MCP 클라이언트도 같은 방식으로, vimong --mcp를 stdio 서버로 실행하도록 등록하면 됩니다.

도구

get_current_view문서 경로, 현재 페이지, 전체 페이지 수
get_selectionVimong에서 선택한 텍스트
get_page_text페이지 텍스트를 마크다운으로 (글자 크기로 제목 인식)
get_page_image페이지를 이미지로 — 그림, 수식, 스캔 페이지
get_notes하이라이트(하이라이트한 문장 포함)와 메모
get_outline목차와 페이지 번호
search_text단어·구절을 찾아 매치마다 페이지와 앞뒤 문맥을 반환
goto_pageVimong 화면을 해당 페이지로 이동
add_highlight시작·끝 구절로 찾은 문장을 하이라이트하고, 코멘트가 있으면 메모로 붙임
save_pages페이지를 새 PDF로 저장
save_markdown페이지를 마크다운 파일로 저장

페이지 인자를 생략하면 지금 보는 페이지가 대상이고, 3, 1-3,7, all 형식도 받습니다.

알아두면 좋은 점

Vimong이 실행 중이고 문서가 열려 있어야 합니다. AI는 요청할 때마다 지금 보고 있는 문서와 페이지를 다시 확인하므로, 대화 도중에 문서나 페이지를 바꿔도 됩니다.

AI가 추가한 하이라이트는 직접 칠한 것과 똑같이 동작합니다. :w로 저장하기 전까지는 파일에 쓰이지 않고, u로 취소할 수 있습니다. 하이라이트와 메모는 PDF 파일에서 동작합니다.

읽기 도구는 디스크의 파일을 읽기 때문에, :w로 저장하지 않은 하이라이트와 메모는 포함되지 않습니다.
