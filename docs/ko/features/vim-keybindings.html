Vim 키바인딩 지원

Vimong은 처음부터 "마우스 없이 문서를 읽는다"는 전제로 만들어졌습니다. 화면 전체에 걸린 단 하나의 keydown 리스너가 지금 상태(일반/명령/검색 모드)에 따라 키 입력을 해석하는, vim과 같은 모드 기반 구조입니다.

이동

j / k아래 / 위 스크롤
h / l좌 / 우 스크롤
Ctrl+D / Ctrl+U반 페이지 아래 / 위로 스크롤
J / K다음 / 이전 페이지
gg / G첫 페이지 / 마지막 페이지
nGn번째 페이지로 이동 (예: 5G)

마크

vim처럼 자주 돌아올 위치를 마크로 저장해두고 즉시 점프할 수 있습니다.

m{a-z}현재 위치를 마크로 저장
'{a-z} / `{a-z}저장한 마크로 이동

그 밖의 모드

ga클릭한 글자의 아스키/유니코드 값을 상태 표시줄에 보기
[ / ]사이드바 탭 전환 (썸네일 / 목차 / 검색)
Tab사이드바 ↔ 본문 포커스 전환
p프레젠테이션 모드 — 전체화면으로 전환하고 한 페이지를 화면에 꽉 채워 슬라이드처럼 보기
:명령줄 모드 진입 (:e, :w, :export 등)

전체 목록은 키 매핑 페이지에서 확인하세요. 앱 안에서는 :? 명령이나 도움말 메뉴로 같은 표를 언제든 다시 볼 수 있습니다.
