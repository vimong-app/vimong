페이지 내보내기

발표 자료에 넣을 표 한 장, 블로그에 붙일 그림 한 장 — 페이지 전체를 이미지나 PDF로 뽑아내는 데 별도 캡처 도구가 필요 없습니다. 파일 메뉴의 "내보내기"나 :export 명령으로 바로 처리합니다.

포맷

PNG, JPG, PDF 세 포맷을 지원합니다. 여러 페이지를 지정하면 기본적으로 페이지마다 별도 파일(번호가 붙음)로 저장되고, "합치기" 옵션을 켜면 이미지는 위아래로 이어붙인 한 장으로, PDF는 한 파일로 합쳐집니다.

내보낼 페이지 고르기

세 가지 방법으로 내보낼 페이지를 지정할 수 있습니다.

페이지 스펙 직접 입력예: 1-3,7-8,20-22
썸네일 다중 선택사이드바 썸네일에서 Cmd+클릭/Shift+클릭으로 페이지를 고르면 내보내기 스펙에 자동으로 채워짐
목차에서 섹션 선택목차 패널에서 헤딩을 클릭한 뒤 내보내기를 열면 그 섹션(하위 항목 포함) 페이지 범위가 자동으로 채워짐

PDF 암호

PDF로 내보낼 때는 암호를 함께 설정할 수 있습니다. 명령줄에서는 :export -p [pagespec] <path.pdf>처럼 -p 옵션을 붙입니다.

저장 위치

기본적으로 원본 문서와 같은 폴더에 저장됩니다. 이미 같은 이름의 파일이 있으면 덮어쓰기 전에 확인합니다.
