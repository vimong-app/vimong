macOS · Windows (not yet) · Linux (not yet)

Features

Vim keybindings

j/k/h/l scrolling, gg/G page jumps, and mark drop/jump — real Vim keybindings throughout.

Regex search

Search document text with vim-style regular expressions.

Link hints

Press f to label every link on the page, then type a letter to jump.

Export pages

Export pages as PNG, JPG, or PDF, and merge multiple pages into a single image.

Font usage breakdown

See which fonts are used in the document and in what proportion.

Fast zoom

Switch instantly between zoom levels, actual size, and fit-to-width/height.

Page rotation

Rotate pages 90° at a time with r / R. Works for both PDF and HWP.

SyncTeX support

Uses SyncTeX to sync with your editor, jumping forward and backward between source and PDF.

HWP support

Open Korean HWP documents right alongside your PDFs.

Image extraction

The :images command saves every image on the current page, byte-for-byte, with no re-encoding.

Highlight / Notes

⌘3 highlights text, ⌘4 drops a note, and :w saves them into the original file.

Markdown support

View .md files in code, preview, or split view, with source highlighting and the same vi keybindings and regex search.

Optional content layers

Toggle PDF layers (OCG) from the sidebar. Nested layer groups from GIS/CAD exports show up indented as a tree, just like the outline.
