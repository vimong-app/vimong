Key Mappings

The complete set of key mappings available in Vimong.

Navigation

j / kScroll down / up
h / lScroll left / right
Ctrl+D / Ctrl+UScroll half page down/up
J / KNext / previous page
ggFirst page
gaShow ASCII/Unicode value of clicked character
GLast page
nGGo to page n (e.g. 5G)
m{a-z}Save current position as a mark
'{a-z} / `{a-z}Jump to a saved mark
fShow link hints, then jump
[ / ]Switch sidebar tab (thumbnails/TOC/search)
TabToggle focus: sidebar ↔ document
j / k (when sidebar focused)Move between thumbnails/TOC/search result items
← / → or h / l (when TOC focused)Collapse/expand chapter, move to parent/child
Cmd+Shift+TShow/hide sidebar
r / RRotate the page 90° clockwise / counterclockwise (works for both PDF and HWP)
pPresentation mode (enter full screen and fit one page to the screen like a slideshow)

Zoom

ziZoom in
zoZoom out
z0100% size
zhFit width
zv / zzFit height
Cmd++Zoom in
Cmd+-Zoom out

File

:eOpen file (dialog)
:e {path}Open file by path (Cmd+V to paste)
:q / Cmd+WClose current tab
:?Open shortcuts help
:cmdOpen commands help
:ossOpen open-source licenses
Cmd+IDocument info
:attachments / :attShow attachment list (sidebar)
:print / Cmd+PPrint
:export [-m] [-p] [pagespec] <path> / Cmd+Shift+EExport as image (PNG/JPG) or PDF. Without pagespec, uses selected pages, or the current page (whole document for PDF). -p sets a password (PDF only)
:imagesSave images embedded in the current page to a folder, byte-for-byte
:view {mode}Switch view mode — single/1, single-continuous/1c, two/2, two-continuous/2c, horizontal-continuous/h
dd (start screen)Remove the selected recent file from the list

Search

/ / Cmd+FSearch (Korean/Japanese/Chinese supported)
n / NNext / previous match
:nohlsearch / :nohClear search highlighting (re-enabled by next search/n/N)
...\c / ...\CAppend to search term to ignore/match case (overrides the Aa toggle)
...\r / ...\RAppend to search term to force regex on/off (overrides the .* toggle)

Supported regex syntax (vim magic mode)

. * ^ $Any character / zero or more / line start / line end
[...] [^...]Character class / negated character class
\+ \? \=One or more / zero or one
\{n,m} \{-...}Specify repeat count (prefix with - for lazy matching)
\( \) \|Group / OR
\< \>Word boundary (start / end of word)
\zs \zeSet start / end of the match (highlight) range
\d \D \w \W \s \SDigit / non-digit / word char / non-word char / whitespace / non-whitespace
\a \l \u \x \o \hLetter / lowercase / uppercase / hex digit / octal digit / identifier char (uppercase = negated)

Unsupported: lookaround (\@= \@! \@<= \@<!), backreferences (\1–\9), \%(...\)

Markdown

Only active when a .md document is open. See the Markdown support page for details.

gc / gp / gsSwitch to code / preview / split view
:md code / :md preview / :md splitSame thing as a command (:md c/p/s also work)
:md theme [name]Switch preview theme (no name cycles to the next one)

Tabs

Cmd+TNew tab
:tabnewNew tab
:tabnew {path} / :tabe {path}Open file in a new tab
:tabcloseClose current tab
:tabonly / :taboClose all other tabs, keep only the current one
gt / gTNext / previous tab
Cmd+Shift+] / Cmd+Shift+[Next / previous tab
ngtGo to tab n (e.g. 2gt)
:tabmove [N]Move tab position (no arg = last, 0 = first, +N/-N = relative)
