Fast zoom

Instead of pinch-zooming on a trackpad or hunting through a menu, switch to the exact zoom level you want with a single key.

ziZoom in
zoZoom out
z0Actual size (100%)
zhFit to window width
zv / zzFit to window height
Cmd++ / Cmd+-Zoom in / out

Read a long paper fit-to-width with zh, switch to zv to see a whole page when a table or figure shows up, and drop into p presentation mode when it's time to present — all without leaving the keyboard.
