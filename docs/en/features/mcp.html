AI integration (MCP)

Vimong ships a built-in MCP server, so AI assistants such as Claude can work with the document you have open in Vimong. No copying text into the chat — just say "this page" or "the selected sentence".

What you can ask

"Summarize this page"Reads the page you're viewing
"Translate the selected sentence"Reads the text you selected in Vimong
"Explain this figure"Looks at the page as an image — figures, equations, scanned pages
"Go to chapter 3"Finds the chapter in the table of contents and moves Vimong there
"Highlight the key claims on this page and comment on each"Adds highlights, with comments as sticky notes
"Make study notes from my highlights"Reads your highlights and notes

You don't need to name Vimong each time. If you also have other document tools connected, saying "in Vimong" removes any doubt.

Setup

Register Vimong with Claude Code:

claude mcp add -s user vimong -- /Applications/Vimong.app/Contents/MacOS/vimong --mcp

Or with Claude Desktop, add this to ~/Library/Application Support/Claude/claude_desktop_config.json, then quit and relaunch Claude Desktop:

{
  "mcpServers": {
    "vimong": {
      "command": "/Applications/Vimong.app/Contents/MacOS/vimong",
      "args": ["--mcp"]
    }
  }
}

On Windows and Linux, use the path to the installed vimong executable instead. Any other MCP client works the same way: run vimong --mcp as a stdio server.

Tools

get_current_viewDocument path, current page and page count
get_selectionText selected in Vimong
get_page_textPage text as Markdown (headings detected from font size)
get_page_imagePage rendered as an image — figures, equations, scanned pages
get_notesYour highlights (with the highlighted text) and notes
get_outlineTable of contents with page numbers
search_textFind a word or phrase and get each match with its page and surrounding text
goto_pageMove Vimong to a page
add_highlightHighlight a passage (found by its first and last words), optionally with a comment note
save_pagesSave pages as a new PDF
save_markdownSave pages as a Markdown file

Page arguments default to the page you're viewing; they also accept 3, 1-3,7 or all.

Good to know

Vimong must be running with a document open. The AI always checks what you're viewing right now, so switching documents or pages mid-conversation is fine.

Highlights the AI adds behave exactly like your own: they stay unsaved until you save with :w, and u undoes them. Highlights and notes work on PDF files.

Reading tools read the file on disk, so highlights and notes not yet saved with :w aren't included.
