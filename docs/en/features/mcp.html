AI integration

Formats:PDFEPUBXPSImagesand more — not HWP; Markdown in the app only

There are two ways to bring AI to the document you're reading:

In VimongPress a and ask a model running on your own computer (Ollama). Your documents never leave your machine
From other AI appsClaude and other assistants read the page you're on, see figures, highlight passages and jump pages, through Vimong's built-in MCP server

In Vimong (local AI)

Press a to open the AI tab in the sidebar and ask about the page you're reading. Answers come from a model running on your own computer through Ollama, so your documents never leave your machine and no account or API key is needed.

Keys

aOpen the AI tab in the sidebar and start typing
:ai / :ai {question}Open the AI tab, or ask right away
Enter / Shift+EnterSend / new line
↑ / ↓Previous / next question you asked
EscStop a reply in progress, or go back to the document
:ai save / Save buttonSave a reply as a Markdown file — page images it was given are saved next to it and linked
[ / ]Switch sidebar tabs — the AI tab is one of them

What the AI sees

Pick what goes along with each question from the menu at the top of the panel. Text you have selected is always included, so "translate this" or "what does this mean?" works on the selection.

This page (text)The text of the page you're viewing — "summarize this page"
Whole file (text)The text of the whole file you're viewing — "what is the conclusion?" (see below for long files)
This page (text + image)The page text plus a picture of the page — figures, tables, equations and scanned pages. Needs a vision model

With "Whole file (text)", asking about a chapter, a section or a page range — "summarize chapter 16" — makes Vimong find that part in the outline and read every page of it, in several passes when it is long. The reply lists what was read. Other questions are answered by searching the file when the model supports tools, such as qwen3 and llama3.1; with other models, the first 40,000 characters are sent.

To pick the part yourself, right-click entries in the outline (or press o on one), or pages in the thumbnails, and choose Ask AI.... The AI tab then shows the scope above the input, and every question reads that whole part until you clear it with ✕.

The document is read at the moment you ask, so after turning pages, "this page" means the page you're on now. Each file keeps its own conversation.

Setup

Install Ollama and download a model:

brew install ollama
ollama serve            # not needed if you use the Ollama app
ollama pull qwen3:8b    # questions about text
ollama pull qwen2.5vl:7b  # figures and scanned pages (vision)

Choose the model from the menu in the panel; it lasts until you quit. In Settings → AI you set the default model and what to send by default, update installed models, download new ones, and point Vimong at Ollama on another computer. On a Mac with 16 GB of memory, models of 7–14B parameters (5–9 GB) run comfortably; for vision, gemma3:12b and llama3.2-vision:11b also work.

Prefer another local AI app? Set Server to OpenAI-compatible in Settings → AI to use LM Studio (fast on Apple Silicon with MLX), llama.cpp's llama-server, MLX-LM, Jan and other servers that speak the OpenAI API. Start the app's local server and load a model there, and give it a context length of 16k or more. Downloading and updating models then happens in that app.

Vimong connects to Ollama at 127.0.0.1:11434 unless you set another address in Settings → AI (or OLLAMA_HOST). Only http addresses are supported.

Good to know

If a file's content can't be sent — a password-protected PDF, an HWP file, or a scanned page with no text — the reply says so, and the answer is made from your question alone. For scans, switch to "This page (text + image)".

Markdown files send their source text, whichever option you pick.

Long code blocks in a reply show their first lines; Show all opens the full code in a window where you can copy it (j/k to scroll, Esc to close).

From other AI apps (MCP)

Vimong ships a built-in MCP server, so AI assistants such as Claude can work with the document you have open in Vimong. No copying text into the chat — just say "this page" or "the selected sentence".

What you can ask

"Summarize this page"Reads the page you're viewing
"Translate the selected sentence"Reads the text you selected in Vimong
"Explain this figure"Looks at the page as an image — figures, equations, scanned pages
"Go to chapter 3"Finds the chapter in the table of contents and moves Vimong there
"Highlight the key claims on this page and comment on each"Adds highlights, with comments as sticky notes
"Make study notes from my highlights"Reads your highlights and notes

You don't need to name Vimong each time. If you also have other document tools connected, saying "in Vimong" removes any doubt.

Setup

Register Vimong with Claude Code:

claude mcp add -s user vimong -- /Applications/Vimong.app/Contents/MacOS/vimong --mcp

Or with Claude Desktop, add this to ~/Library/Application Support/Claude/claude_desktop_config.json, then quit and relaunch Claude Desktop:

{
  "mcpServers": {
    "vimong": {
      "command": "/Applications/Vimong.app/Contents/MacOS/vimong",
      "args": ["--mcp"]
    }
  }
}

On Windows and Linux, use the path to the installed vimong executable instead. Any other MCP client works the same way: run vimong --mcp as a stdio server.

Tools

get_current_viewDocument path, current page and page count
get_selectionText selected in Vimong
get_page_textPage text as Markdown (headings detected from font size)
get_page_imagePage rendered as an image — figures, equations, scanned pages
get_notesYour highlights (with the highlighted text) and notes
get_outlineTable of contents with page numbers
search_textFind a word or phrase and get each match with its page and surrounding text
goto_pageMove Vimong to a page
add_highlightHighlight a passage (found by its first and last words), optionally with a comment note
save_pagesSave pages as a new PDF
save_markdownSave pages as a Markdown file

Page arguments default to the page you're viewing; they also accept 3, 1-3,7 or all.

Good to know

Vimong must be running with a document open. The AI always checks what you're viewing right now, so switching documents or pages mid-conversation is fine.

Highlights the AI adds behave exactly like your own: they stay unsaved until you save with :w, and u undoes them. Highlights and notes work on PDF files.

Reading tools read the file on disk, so highlights and notes not yet saved with :w aren't included.
