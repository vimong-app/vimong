Markdown Support

Vimong handles .md files with the same vi keybindings it uses for PDFs. Switch between the raw source, a rendered preview, and a split view showing both side by side.

Switching views

gc / gp / gsSwitch to code / preview / split view
:md code / :md preview / :md splitSame thing as a command (:md c/p/s also work)
:md theme {name}Switch the preview color theme. No name cycles to the next one; Tab autocompletes the name

In split view, scrolling either pane keeps the other one pointed at the same spot in the document.
