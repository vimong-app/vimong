Page rotation

Run into a page scanned sideways or oriented the wrong way? Rotate it with a single key instead of digging through a menu.

rRotate 90° clockwise
RRotate 90° counterclockwise

Works for PDF and HWP

Rotation only affects the view, not the document itself, so saving or exporting keeps the original orientation. It works the same way in HWP documents as it does in PDF.
