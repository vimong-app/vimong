HWP support

Powered by rhwp, HWP files open directly too, with no separate conversion step.

What's supported

  • · Vim keybindings navigation — j/k scrolling, gg/G, nG, marks (m/')
  • · Zoom — zi/zo/z0/zh/zv/zz
  • · Page rotation — r/R
  • · Regex search

What's not supported

HWP is supported as a minimal viewer, so a few things that work in PDF don't.

  • · Link hints (f) — hints don't appear even when links are present
  • · Export pages (:export) / PDF extraction (:w) — not supported
