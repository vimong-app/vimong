SyncTeX support

Writing LaTeX means constantly asking "what line is this sentence on in the source?" and "where does this line show up in the PDF?" SyncTeX integration lets you jump both directions between your editor and the PDF.

Backward search (PDF → source)

Shift+Cmd+Click / Shift+Ctrl+ClickOpen your editor at the LaTeX source line corresponding to the spot you clicked in the PDF

Forward search (source → PDF)

Trigger a SyncTeX forward search from your editor and Vimong jumps to the exact spot on the corresponding PDF page.

Editor integration

The SyncTeX tab in Settings is where you set which editor command backward search opens. Use the VS Code preset directly, or write a custom command using the %f (file), %l (line), and %c (column) placeholders.

TeXShop doesn't ship its own SyncTeX CLI, so it needs a small helper script — Settings gives you a one-line install command to copy and paste into Terminal.
