Split view

Formats:PDFEPUBXPSImagesand more — not HWP or Markdown

Keep a figure or the bibliography open while you read, or put a paper next to its supplement. Like Vim, :vsplit and :split divide the view into two windows, and you move between them with Ctrl+W.

:split [path] / :spSplit top/bottom — opens path, or the current document
:vsplit [path] / :vsSplit left/right — opens path, or the current document
:e [path]In the split window: change only its document
Ctrl+W wSwitch to the other window
Ctrl+W h / j / k / lMove to the window in that direction
:q / :close / Ctrl+W cClose the current window — the other one stays (the document stays open)
:only / Ctrl+W oClose the other window

Each window on its own

The split window has its own position, zoom and rotation: j/k, J/K, gg/G, {n}G, Ctrl+D/U, zi/zo/zh/zv/zc and r/R all work in whichever window is active. It keeps its document when you switch tabs, reloads when the file changes on disk (handy for LaTeX), and comes back with tab session restore.

Sidebar and search follow the active window

The table of contents in the sidebar belongs to the active window: pick a heading and that window moves, and when the split window shows a different document you see that document’s outline. Search is per window too — /, n/N and the search panel act on the active window, and searching in one window leaves the other window’s results alone. The other sidebar tabs stay on the main document.

Split view works with documents MuPDF opens — PDF, EPUB, XPS, images and so on. HWP and Markdown files open in the main window only.
