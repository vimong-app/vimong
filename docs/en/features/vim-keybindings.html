Vim keybindings

Vimong was built from day one around a single premise: read documents without touching the mouse. A single keydown listener spans the whole window and interprets keys based on the current mode (normal / command / search) — the same modal design as vim itself.

Navigation

j / kScroll down / up
h / lScroll left / right
Ctrl+D / Ctrl+UHalf-page scroll down / up
J / KNext / previous page
gg / GFirst page / last page
nGGo to page n (e.g. 5G)

Marks

Just like vim, drop a mark on any spot you'll want to return to, and jump straight back.

m{a-z}Set a mark at the current position
'{a-z} / `{a-z}Jump to a saved mark

Other modes

gaShow the ASCII/Unicode value of a clicked character in the status bar
[ / ]Switch sidebar tab (thumbnails / outline / search)
TabToggle focus between sidebar and document
pPresentation mode — full screen with one page fit to the screen, like a slideshow
:Enter command-line mode (:e, :w, :export, ...)

See the full list on the key mapping page. Inside the app, :? or the Help menu brings up the same table any time.
